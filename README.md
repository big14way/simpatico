# Simpatico

**An agentic deal desk for brand acquisitions, licensing and co-branding.**

> Every deal model has a spreadsheet for revenue. Nobody has one for whether the customers will get along. Simpatico does, and it shows its work.

You give Simpatico a buyer (a brand plus a few flagship proxies) and a deal type. It:

1. resolves every name to a Qloo entity, asking you to confirm anything ambiguous;
2. screens a universe of candidate brands against the buyer's audience using Qloo's taste graph;
3. computes six audience-fit metrics in code from logged Qloo responses;
4. runs a bull agent and a bear agent on each shortlisted target, and a code judge rejects any claim the evidence ledger doesn't back;
5. writes an investment-committee memo whose every number is checked against the ledger;
6. updates the pipeline, drafts outreach that only sends after human approval, and re-scores the pipeline on a schedule.

Without Qloo it refuses to score anything. **Simpatico doesn't guess. Connect Qloo.**

> Status: under active development during the Qloo LLM Hackathon 2026 submission period. Built from scratch.
